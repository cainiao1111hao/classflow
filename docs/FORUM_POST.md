## 标题

开源分享：课序 ClassFlow，一个离线可用的课程任务与番茄钟工具

## 正文

大家好，我整理了一个面向大学生日常学习的小工具——**课序 ClassFlow**，目前版本是 **1.0.0**，采用 **MIT 许可证**。

做这个工具是因为课程作业、实验报告和复习任务常常分散在不同地方。我想把“接下来要做什么”和“实际投入了多少时间”放在同一个页面，减少来回切换。

### 主要功能

- 添加和编辑任务，记录课程、截止日期、优先级与完成状态。
- 按课程和时间范围筛选，搜索任务并查看逾期情况。
- 用番茄钟专注于某项任务，设置学习与休息时长。
- 查看任务概览和最近 7 天的学习时长。
- 导出 JSON 备份、恢复数据，或导出任务 CSV。

### 怎么使用

下载完整源码包并解压，双击 `index.html` 即可打开。如果 Release 附有单文件版 `classflow.html`，可以直接下载并双击该文件。已安装 Node.js 20 或更新版本的同学也可以运行 `node server.cjs`，再访问 `http://localhost:4173`。

数据保存在自己的浏览器中，不会上传到服务器。请定期导出 JSON 备份；换浏览器或清理浏览器数据前尤其需要备份。部分浏览器限制本地文件页面保存数据，遇到这种情况请改用本地服务器方式。

### 当前限制与后续维护

第一版是单人离线工具，暂时没有账号同步、多人协作和系统级通知。浏览器关闭或设备休眠时，计时页面可能无法及时运行，因此不承诺后台提醒。

后续准备先处理真实使用反馈，检查任务筛选、备份恢复和移动端操作，再根据需要完善体验。遇到问题时，欢迎告诉我浏览器版本、打开方式和复现步骤。请不要直接上传含个人信息的完整备份。

初始版本使用了 AI 协助开发，我会继续阅读代码、实际验证并维护。也欢迎对代码结构、错误处理和实际使用体验提出建议。
