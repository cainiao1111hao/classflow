# 课序 ClassFlow

一个面向大学生的离线课程任务助手。把作业截止日期、学习任务和专注记录放在一起，打开浏览器即可使用。

**当前版本：1.0.0 · MIT 开源许可证 · 无运行时第三方依赖**

## 可以做什么

- 管理任务：添加、编辑、删除、标记完成，记录课程、截止日期和优先级。
- 找到眼前的事：搜索任务，按课程、今天、未来七天或完成状态筛选，并按截止日期等条件排序。
- 专注学习：设置学习与休息时长，关联一个任务，使用可暂停的番茄钟。
- 回看投入：统计任务完成情况、逾期任务与最近 7 天的学习时长。
- 自己保管数据：导出 JSON 备份、恢复备份，或导出任务 CSV。

首次打开是空白工作区。需要了解用法时再主动加载示例数据；示例不是你的学习记录。正式使用前，请清除示例或恢复自己的备份。

## 立即使用

### 方法一：直接打开

下载并解压完整项目，双击 `index.html`。让脚本和样式保留在同一目录，即可离线使用。

部分浏览器对 `file://` 页面的本地存储有限制。如果保存失败或刷新后数据丢失，请使用下面的本地服务器方式。

如果下载的是发布包中的单文件版 `classflow.html`，可直接双击该文件，无需配套脚本和样式。单文件版与源码入口是不同的访问地址，迁移数据时也要先导出再导入。

### 方法二：本地服务器

电脑已安装 Node.js 20 或更新版本时，在项目目录打开终端，运行：

```text
node server.cjs
```

然后在浏览器打开 <http://localhost:4173>。关闭服务器时在终端按 `Ctrl+C`。程序无需 `npm install`。

## 建议的首次操作

1. 在「课程任务」中添加一项作业，填写课程、截止日期和优先级。
2. 在「专注时光」中选择该任务，完成一段专注后查看学习统计。
3. 标记完成，检查完成数量是否更新。
4. 在「数据与备份」中导出 JSON，将文件保存在浏览器以外的位置。

CSV 适合查看任务或做表格分析。JSON 备份包含任务、已完成的专注记录和设置。导入会覆盖当前数据并要求确认，操作前请先导出手头的记录。

## 数据与已知限制

- 任务、设置与已完成的专注记录保存在当前浏览器的 `localStorage` 中。应用离线运行，数据保存在本机。
- 清理浏览器数据、使用无痕模式、移动文件，或切换浏览器、访问地址、协议和端口，可能改变数据的存储位置。迁移前先导出 JSON，再在新环境导入。
- 页面按目标结束时间计算剩余时长，减少标签页进入后台时的计时误差。正常关闭页面时会暂停计时，重新打开后可以继续。完成整段专注才会计入统计，提醒仅显示在页面内。
- 本版本是单人、单浏览器工具，不提供账号、云同步和多人协作。请避免同时在多个标签页修改同一份数据。
- 截止日期和专注统计使用电脑的本地日期，依赖设备时间和时区设置。
- 备份和 CSV 可能含任务名、课程名等个人信息，分享问题时请先脱敏。

## 项目结构

```text
classflow/
├─ index.html              页面入口
├─ app.js                  界面与浏览器存储
├─ core.js                 校验、筛选、统计、CSV 等纯逻辑
├─ styles.css              页面样式
├─ server.cjs              可选的本地静态服务器
├─ scripts/build.cjs       可选的单文件版构建脚本
├─ tests/                  使用 Node.js 内置测试工具的测试
├─ docs/                   发布、维护与演示材料
├─ CHANGELOG.md            真实的版本变更记录
├─ CONTRIBUTING.md         贡献约定
└─ LICENSE                 MIT 许可证
```

界面事件由 `app.js` 处理。它把任务、专注记录和设置交给 `core.js` 校验，再保存到浏览器并刷新界面。筛选和统计由 `core.js` 根据本地日期计算，可以脱离页面单独测试。备份导入先校验文件格式和记录内容，再由用户确认替换。

## 开发与验证

建议使用 Node.js 22 或更新版本。在项目目录执行测试。

```text
npm test
```

修改界面后，用浏览器检查任务增删改查、倒计时、刷新后数据保留、备份导出和恢复以及窄屏布局。

用以下命令生成可独立打开的单文件版。

```text
node scripts/build.cjs
```

输出为 `dist/classflow.html`。修改源码后重新构建并验证该文件。发布源码时保留许可证、测试与文档。
